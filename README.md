# Basketball Game Analysis with YOLO and OpenCV

This project combines sports and technology by leveraging **YOLO**, **OpenCV**, and **Python** to detect players, referees, and basketballs in game footage. The goal is to generate comprehensive statistics and metrics that enable detailed basketball game analysis.  

## Features
- Custom YOLO object detector trained with annotated data from Roboflow  
- Accurate detection of players, referees, and basketballs in real-time video  
- Integration with OpenCV for video processing and frame-by-frame analysis  
- Foundation for generating advanced game statistics and insights  

## Tech Stack
- Python  
- YOLO (You Only Look Once)  
- OpenCV  
- Roboflow (for dataset annotation and preprocessing)  

## Future Work
- Automated player and team tracking
- Ball possession and movement metrics
- Comprehensive statistical dashboards
